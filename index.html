What this is

A free, searchable directory of UPSC Civil Services Mains topper answer copies. You can search across every question inside the copies and jump straight to the page where a topper answered it.

Credit

The question-level database — which topper wrote which answer, on which page of which copy — is the work of upsckata.com's "Topper Copies" project. This site is an independent, non-commercial mirror that adds an optional-subjects section, per-topper AIR / marks tags, and a community submission workflow. All credit for the underlying data collection goes to upsckata.com. If the maintainers of that project want changes to how it's credited or used here, open an issue.

Where the PDFs live

Every "Open PDF" link points to a file hosted by the institute that originally published it — ForumIAS, Vision IAS, NextIAS, Lukmaan IAS, GS SCORE, Rau's IAS and others. No answer copy is stored on this domain. If you are a rights holder and want a link removed, file an issue and it will be taken down.

Contributing

  • Use the Submit tab to add a missing copy or an optional-subject copy.
  • Use it also to fill in a topper's AIR, exam year, or subject-wise marks.
  • Every submission becomes a GitHub issue, is checked by a maintainer, then merged.
  • Code and data live at github.com/hashin/topperscopy — PRs welcome.
